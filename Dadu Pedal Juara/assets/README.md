# Assets Folder - Dadu Emosi

Place your own Canva export files for the 6 sides of the dice in this folder to load them automatically.

## Naming Conventions
To load them automatically on startup, name the files exactly as follows:
- **Face 1 (Bahagia)**: `face1.png` (or `face1.jpg`)
- **Face 2 (Sedih)**: `face2.png` (or `face2.jpg`)
- **Face 3 (Marah)**: `face3.png` (or `face3.jpg`)
- **Face 4 (Takut/Gugup)**: `face4.png` (or `face4.jpg`)
- **Face 5 (Terkejut)**: `face5.png` (or `face5.jpg`)
- **Face 6 (Mual/Menjijikkan)**: `face6.png` (or `face6.jpg`)

Alternatively, you can click the settings icon (sliders) in the app interface to upload them directly from your browser. Uploading from the browser will save them locally to your browser's persistent storage (IndexedDB) so they persist even when the page is refreshed!
